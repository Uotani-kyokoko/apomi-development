   ## この説明書について

   プレジデントメイト（PRESIDENT MATE）は、**社長マークが承認された人だけ**が使えるマッチングです。  
   操作の多くは Apomy と同じです。この文書では **プレジデントメイト特有の使い方** を説明します。

   | 読みたい人 | 見る章 |
   |------------|--------|
   | はじめて使う社長 | 1〜5章 |
   | 社長申請・承認の流れ | 3章 |
   | 掲載の出し分け | 5章 |
   | 運用（スプシ） | 6章 |
   | 困ったとき | 7章 |

   ---

   ## 1. プレジデントメイトとは

   - **対象**: 社長マーク承認済みの会員だけ
   - **データ**: Apomy・みんつくと **同じ会員表**（人は1人1行）
   - **お金**: **課金なし**（当面、無料期間の設定もありません）
   - **見た目**: 専用ログイン・専用アイコン（黒〜金、PRESIDENT MATE）
   - **一覧**: 全国の承認済み社長（地方制限なし）

   Apomy（全国）・みんつく（地方）・プレジデントメイトは **掲載のON/OFFが独立** しています。  
   Apomyの掲載を止めていても、プレジデントメイトには出ることがあります。

   ---

   ## 2. 入れる条件

   ### 入れる人

   - Googleでログインできる
   - 会員表で **社長マーク＝TRUE（承認済み）**

   ### 入れない人

   | 状態 | 挙動 |
   |------|------|
   | 未ログイン | 専用ログイン画面 |
   | 社長マークなし／申請中／却下 | トーストで案内し、入室不可 |

   ログイン拒否時の文言:

   > Apomyにて社長マークの承認をお願いします

   ### 社長マークの申請は Apomy で

   - プレジデントメイトのマイページに **社長申請ボタンは出ません**
   - 申請・承認は **Apomy** の従来フロー（マイページ → 運用確認）

   ---

   ## 3. 開き方

   ### Apomyから（一般公開時）

   1. Apomy にログイン
   2. 「**条件から絞り込む**」を開く
   3. 「**プレジデントメイト**」を押す（「地域を選ぶ」の下）

   | 社長マーク | 結果 |
   |------------|------|
   | 承認済み | プレジデントメイトへ進む |
   | 未承認 | 遷移せず「社長承認者のみ…」と案内 |

   **運用メモ**: 公開前のテストなど、Apomyのボタンを **一時非表示** にしている場合は、下記 URL で開いてください。

   ### URLで開く場合

   ```
   …/president/index.html
   ```

   または同等:

   ```
   …/index.html?app=president
   ```

   開発: `https://uotani-kyokoko.github.io/apomi-development/president/index.html`  
   本番: `https://fortunatunabiz.github.io/Apomy/president/index.html`

   ### ホーム画面に追加

   1. プレジデントメイトをブラウザで開く
   2. マイページの **インストールボタン** から追加
   3. 名前は **PRESIDENT MATE**、専用アイコンになります

   ---

   ## 4. ログインと初回

   1. Googleアカウントでログイン（社長マーク必須）
   2. プロフィール未登録なら、案内に従って登録
   3. 初めてプレジデントメイトを使うと、次が自動で行われることがあります
      - **プレジデントメイト掲載** が空欄なら **TRUE**（明示停止中は除く）
      - **プレジデント番号** の採番（例: `社長12` → 画面では `No.00012`）

   **補足**: 本人がまだ一度も入っていなくても、運用が社長マークをONにしていれば **一覧候補** になります。  
   番号は **誰かが一覧を開いたとき** または **本人が初回入室したとき** に付きます。

   ## 5. 画面の使い方

   | タブ | できること |
   |------|------------|
   | ホーム | ダッシュボード・バナー（プレジデント向けのみ） |
   | 繋がる | 承認済み社長の一覧・絞り込み |
   | マイページ | プロフィール・プレジデントメイト掲載の停止／再開 |

   ### 繋がる

   - 一覧条件: **社長マーク=TRUE** かつ **プレジデントメイト掲載≠FALSE**（空欄も掲載）
   - Apomyの `掲載中` やみんつくの掲載は **見ません**
   - 番号は **プレジデント番号**（`No.00012` 形式）
   - 繋がるメニューは **社長帯のみ**（サロン帯・通常帯なし）
   - 社長カードは **白背景** の通常表示（Apomyの暗色社長カードとは異なります）

   ### マイページで出ないもの

   - サロン掲載の申請
   - 社長マークの申請
   - みんつくの掲載操作・利用状況

   ### プロフィール編集（3アプリ共通）

   - **人脈拡大の為の年間経費（非公開）** は保存時に必須
   - **現在地** の30日ロックなど、Apomyと同じルール
   - **社名** は社長マークありの人が編集・表示できます

   ### 掲載の出し分け

   | 操作 | 結果 |
   |------|------|
   | **プレジデントメイトの掲載を停止／再開** | PM一覧だけ止まる／戻る |
   | **Apomyの掲載** | PM内からは直接操作しません（Apomyで別管理） |

   覚え方:

   - **PMに出したくない** → 「プレジデントメイトの掲載を停止」（`プレジデントメイト掲載=FALSE`）
   - **Apomy全国には出したくない** → Apomy側で `掲載中` をOFF（PMには別途影響しません）

   ## 6. 運用担当向け（スプシ）

   ### 会員シート（追加・重要列）

   | 列名 | 運用でやること |
   |------|----------------|
   | 社長マーク | **入室資格**。TRUEでPM利用可・一覧候補 |
   | 社長マーク状態 | 申請中／却下など（参考） |
   | プレジデントメイト掲載 | 空欄・TRUE＝PM一覧に出す／FALSE＝停止 |
   | プレジデント番号 | 原則触らない（`社長N` 自動採番） |
   | 掲載中 | Apomy用。PM一覧では **参照しない** |
   | 社名 | 社長カード表示 |

   社長マークをTRUEにした時点で、本人がPM未ログインでも **一覧候補** になります（掲載列がFALSEでなければ）。

   ### バナーシート

   | 列名 | 内容 |
   |------|------|
   | 対象アプリ | 空欄＝全アプリ。`プレジデントメイト` と書くとPMのみ |

   ### 申請シート

   社長マーク・サロンの申請は **従来どおり Apomy 経由**。PM専用の申請列はありません。

   **注意**: `Code.gs` 変更後は **Apps Script 再デプロイ** が必要です。

   ## 7. 困ったとき

   | 症状 | 確認すること |
   |------|----------------|
   | 入れない | 社長マークがTRUEか。Apomyで承認済みか |
   | 一覧に出ない | `プレジデントメイト掲載` がFALSEになっていないか |
   | 番号が `No.-----` | 一覧取得または本人初回入室後に採番される。少し待つか再読込 |
   | サロン申請が見えない | PMでは **出さない仕様**（Apomyで申請） |
   | Apomyに出ている | PMは `掲載中` を見ない。Apomy停止はApomy側の操作 |
   | プロフィールが保存できない | 年間経費（非公開）を選んだか |
   | 画面が古い | ハードリロード。GAS変更なら再デプロイ |

   ### Apomyで社長申請したいとき

   - **Apomy** を開き、マイページから社長マーク掲載を申請
   - 承認後、プレジデントメイトのURLまたはApomy導線から入る
