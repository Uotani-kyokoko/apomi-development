## はじめに（この文書の読み方）

プレジデントメイトは、**Apomy と同じ仕組みの上に乗る、社長向けの別入口アプリ**です。  
見た目・ログイン・アクセス条件だけを変え、マッチングの基本操作は Apomy に揃えます。

| 読みたい人 | おすすめ |
|------------|----------|
| オーナー・お客様 | 1〜6章 |
| 運用担当 | 5〜8章 |
| エンジニア | 全体。とくに 4・7・9〜11章 |

関連文書:

- Apomy本体 → `Apomy仕様書.md`
- 地方版みんつく → `みんつく仕様書.md`（実装済みの「別モード」前例）

### 用語

| 用語 | 意味 |
|------|------|
| Apomy | 全国向けマッチング（既存） |
| プレジデントメイト | 社長マーク承認者だけが使えるマッチング |
| 社長マーク | Apomyで申請・承認されるバッジ（**入室資格**） |
| プレジデントメイト掲載 | 一覧に出すかのスイッチ。**空欄・TRUE＝出す／FALSE＝隠す** |
| プレジデント番号 | 会員シートの番号。保存は `社長12`、画面は `No.00012` |
| 会員マスタ | 共通の会員シート（人は1人1行） |
| モード | URLなどで切り替えるアプリ種別（apomy / mintuku / president） |
| 社長帯 | 繋がるメニューで、プレジデント番号の帯ごとに見るページ |
| 対象アプリ（バナー） | バナーをどのアプリに出すか。空欄＝全アプリ |

## 1. やりたいこと

> **中身のアプリは1つ。**  
> 社長マークを承認された人だけが入れる「専用の見た目・入口」を用意する。  
> データは Apomy と同じスプレッドシートを使い、**会員マスタは分けない。**

一言で言うと:

**「社長申請・サロンのない Apomy」＋「社長マーク承認者のみアクセス」＋「専用掲載フラグ」＋「専用アイコン・ログイン画面」**

## 2. Apomy / みんつく / プレジデントメイトの違い

### 2.1 一覧表

| 比べる点 | Apomy | みんつく | プレジデントメイト |
|----------|--------|----------|---------------------|
| 対象 | 全国 | その地方 | **社長マーク承認者** |
| 一覧に出す条件（詳細は下） | `掲載中=TRUE` | `みんつく掲載=TRUE` | **`社長マーク=TRUE` かつ `プレジデントメイト掲載 ≠ FALSE`**（空欄も出す） |
| 専用番号 | 会員番号 | みんつく番号（例: 関東12） | **プレジデント番号（例: 社長12）** |
| お金 | 永久無料 | 無料30日→有料 | **課金なし（当面考えない）** |
| サロン申請UI | あり | あり（現状） | **なし** |
| 社長マーク申請UI | あり | あり（現状） | **なし**（承認済みの人だけ） |
| 社長マーク表示 | あり | あり | **あり** |
| 繋がるの帯 | 通常帯＋社長帯＋サロン帯 | 地方向け（みんつく番号） | **社長帯のみ** |
| アイコン・ログイン | Apomy用 | みんつく用 | **プレジデントメイト専用** |
| バナー | 対象アプリ列で出し分け（空＝すべて） | 同左 | 同左 |
| プロフィール編集 | 共通画面 | 共通画面（現在地30日ロックあり） | **共通画面（Apomyと同じ項目・必須）** |
| スプシ | 共通 | 共通 | **共通（会員は複製しない）** |
| GAS | 共通 | 共通 | **共通（モード追加）** |

### 2.2 プレジデントメイトの一覧条件（詳細）

一覧に **出す** のは、次を **両方** 満たす会員だけです。

1. **`社長マーク = TRUE`**（入室資格・候補の前提）  
2. **`プレジデントメイト掲載` が FALSE でない**  
   - **空欄** → 出す（承認済みでまだ一度もPMを開いていなくても出す）  
   - **TRUE** → 出す  
   - **FALSE** → 出さない（本人が掲載停止したとき）  

見ない列:

- Apomyの **`掲載中`** は見ない（Apomy停止中でも、上を満たせばPM一覧には出る）  
- みんつくの掲載フラグも見ない  

入室（ログインして使えるか）は一覧とは別で、**社長マーク=TRUE** が必要。未承認はトーストで拒否する（3章）。

### 2.3 プロフィール編集（共通）

3アプリとも **同じ編集画面・同じ必須項目** を使う（1か所の修正が全体に効く）。

| 内容 | 扱い |
|------|------|
| 名前・性別・年代・業種・職種・現在地・LINE など | 共通（必須には朱書き＊） |
| 現在地の30日ロック | Apomy／みんつく／プレジデントで同じ |
| 社名 | 社長マークありのとき編集可（従来どおり） |
| サロン申請・社長申請ボタン | **プレジデントメイトのマイページには出さない** |

## 3. アクセス条件（ゲート）

### 入れる人

- Googleログインできる  
- 会員シートで **社長マーク＝TRUE（承認済み）**  

### 入れない人

| 状態 | 挙動 |
|------|------|
| 未ログイン | ログイン画面（プレジデントメイト用） |
| ログインしたが社長マークなし／申請中／却下 | **トースト**で案内し、入室させない（Apomyへ戻す） |

拒否時トースト文言（確定）:

> Apomyにて社長マークの承認をお願いします

※ Apomy絞り込み導線の未承認文言（「マイページから社長申請して下さい」）とは別。直URL／ログインゲート用は上記。

### Apomy側との関係

- 社長マークの **申請・承認フローは Apomy（既存）のまま**  
- プレジデントメイトでは申請ボタンを出さない  
- 承認作業は従来どおりスプシ／運用フロー

## 4. 開き方・構成（実装方針）

みんつくと同じ型を踏襲する。

### 入口

```
president/index.html
→ ../index.html?app=president
```

- `app=president` でモード切替（`js/app-mode.js` 拡張）  
- 地方トークンは不要（全国・承認者限定）  

### Apomyからの導線（確定）

**場所:** Apomyの「条件から絞り込む」画面で、**「地域を選ぶ」の下**にボタンを置く。

| 要素 | 内容 |
|------|------|
| ボタン名 | **プレジデントメイト** |
| 社長マークあり | プレジデントメイトへ遷移（`president/` 入口または `?app=president`） |
| 社長マークなし | 遷移せず、次の文言を表示（トースト等） |

表示文言（確定）:

> 社長承認者のみアクセスできます。マイページから社長申請して下さい。

補足:

- みんつくモードの絞り込み画面には、このボタンは **出さない**（Apomy導線）  
- 判定はフロントだけでなく、プレジデントメイト側 GAS でも再確認する  

### 実装方針（合意）

| 方針 | 内容 |
|------|------|
| UI本体 | 共通 `index.html` + `js/`（薄い `president/` 入口のみ） |
| GAS・スプシ | Apomy / みんつくと **同じ1本・1冊** |
| 会員タブ | **分けない・複製しない** |
| 掲載フラグ | みんつくと同じく **専用列で独立** |
| コメント | `[共通]` / `[Apomy]` / `[みんつく]` / `[プレジデント]` を明示 |

### 意図的にやらないこと

- プレジデントメイト専用の会員シートコピー  
- 別GAS・別スプシを最初から作ること  
- サロン／社長マーク申請の再実装  
- **課金・無料期間・問い合わせ課金フロー**（当面スコープ外）

## 5. 掲載の出し分け（みんつくと同方式・確定）

フラグは次のとおり **独立** させる。

| 列 | 意味 |
|------|------|
| `掲載中` | Apomy（全国）の一覧に出すか |
| `みんつく掲載` | みんつく地方一覧に出すか |
| `プレジデントメイト掲載` | **プレジデントメイト一覧に出すか（新規）** |
| `社長マーク` | プレジデントメイトへの **入室資格**（申請・承認は Apomy） |

**一覧の参照ルール（厳守・詳細は2.2章）**

- Apomy一覧 → **`掲載中` のみ**  
- みんつく一覧 → **`みんつく掲載` のみ**  
- プレジデントメイト一覧 → **`社長マーク=TRUE` かつ `プレジデントメイト掲載 ≠ FALSE`**  
  - **空欄も掲載扱い**（承認済みでまだ一度もPMを開いていない人も一覧に出す）  
  - **FALSE だけ非表示**（本人が停止したとき）  

そのため:

- 社長マーク承認済み・掲載フラグ空欄 → **一覧に出る**（初回ログイン前でも可）  
- Apomyだけ停止でも、PM掲載がFALSEでなければ **プレジデントメイトには出る**  
- プレジデントメイトだけ停止（FALSE）→ **プレジデントメイトには出ない**  
- 社長マークが外れたら、入室不可・一覧からも除外  

### プレジデントメイト・マイページ操作（みんつく踏襲）

| 操作 | 結果 |
|------|------|
| プレジデントメイトの掲載を停止／再開 | `プレジデントメイト掲載` を FALSE／TRUE |
| Apomyの掲載を停止／再開 | `掲載中` だけ変更（プレジデント側は触らない） |

### フラグ自動書き込み（確定）

**プレジデントメイトへの初回アクセス時**に、`プレジデントメイト掲載` が空欄なら **TRUE** を書く（空欄のまま一覧に出せるが、明示的にTRUEへ）。

| ルール | 内容 |
|------|------|
| いつ | 社長マーク承認済みの会員が、プレジデントメイトに **初めて入ったとき** |
| 空欄のとき | `プレジデントメイト掲載` を TRUE |
| すでに FALSE | **触らない**（停止を尊重） |
| 承認時 | スプシで社長マークをONにするだけ。掲載フラグは必須ではない（空欄＝一覧に出る） |

### 「承認済みなのにリストに出ない？」への答え

役割を分けるとイメージしやすいです。

| 列 | 役割 |
|------|------|
| `社長マーク` | **資格**（入れる／一覧候補） |
| `プレジデントメイト掲載` | **見せたくないスイッチ**（FALSEで隠す。空欄・TRUEは出す） |

運用が社長マークをTRUEにした時点で、**本人がPM未ログインでも一覧候補になる**。  
番号は **一覧が一度でも開かれたとき**（または本人入室時）に自動で付くので、未ログインの承認者も番号付きで並ぶ。

## 5b. プレジデント番号（確定）

みんつくの「地方＋数値」（例: `関東12`）に合わせる。

| 項目 | 内容 |
|------|------|
| 保存形式 | `社長` + 連番（例: `社長1` / `社長12`） |
| 画面表示 | `No.00012`（数字のみ） |
| 列名 | **`プレジデント番号`** |
| 欠番 | 埋めない |

### 採番タイミング（確定・v0.5）

**「本人の初回ログイン待ち」だけだと、未ログインの承認者が番号なしになる。**  
そのため次のどちらか（実際は両方）で採番する。

| いつ | 内容 |
|------|------|
| A. 本人がPMに初回入室 | 未採番なら `社長N` を付与＋掲載フラグ空欄なら TRUE |
| B. **誰かがPM一覧を取得したとき** | `社長マーク=TRUE` かつ番号空の行へ、まとめて採番（Lock付き） |

これで:

- 運用が社長マークをTRUEにした  
- 本人はまだ一度もPMを開いていない  
- → **別の承認者が一覧を開いた時点で番号が付き、番号順で掲載される**  
- 誰も一覧を開いていなくても、本人が入室した瞬間に採番される  

未採番の瞬間が残っても一覧には出す（空欄掲載扱い）。表示上は末尾→採番後に正規の位置へ。

## 6. 機能範囲（画面）

### あるもの（Apomy相当）

- Googleログイン（専用ブランド）  
- ホーム（ダッシュボード／バナー ※対象アプリで出し分け）  
- 繋がる（一覧・条件絞り込み・プロフィールカード）  
- マイページ（プロフィール・**プレジデントメイト掲載**の停止／再開）  
- ホーム画面への追加（PWA・専用名／アイコン）  

### 繋がるの「帯」（確定）

プレジデントメイトの繋がるメニューは **社長帯のみ**（サロン帯なし・通常の会員番号帯も出さない）。  
並びは **プレジデント番号** の数字順。

### ないもの

- 井口サロン掲載の申請・サロン専用導線・**サロン帯**  
- 社長マーク掲載の申請  
- みんつく地方切替・みんつく課金UI  
- 課金・期限切れ画面  

### Apomy側に追加するもの

- 絞り込み画面「地域を選ぶ」の下の **プレジデントメイト** ボタン（本章4参照）  

### バナー（確定）

バナーシートに **`対象アプリ`** 列を追加する。

| 選択肢（正規） | 意味 |
|--------|------|
| （空）または `すべて` | 全アプリに出す |
| `アポミー` | Apomyのみ |
| `みんつく` | みんつくのみ |
| `プレジデントメイト` | プレジデントメイトのみ |

※ 旧英字（`apomy` / `mintuku` / `president`）も互換で受け付ける。運用の入力値は日本語を正とする。

場所列（ホーム／繋がる／両方）は従来どおり。

#### いくつまで出せる？／遅くなる？

| 事実 | 内容 |
|------|------|
| いまの上限 | **件数のハード上限はない**（有効＋期間内を全部返す） |
| 遅さの主因 | 件数そのものより **画像の枚数・サイズ**（端末が1枚ずつ読む） |
| アプリ列の効果 | 各アプリは自分向けだけ取るので、3アプリ分を全部読まなくてよくなる |

運用目安（推奨・強制ではない）:

| 場所 | 目安 |
|------|------|
| ホーム | **3〜5件**まで |
| 繋がる | **2〜3件**まで |

多くしたい場合は、画像を軽くする・表示順で上だけ厚くする・期間で入れ替える、が有効。  
実装時に「アプリごと・場所ごとに最大N件」のソフト上限を入れることもできる（必要なら別途決める）。

## 8. データ設計（スプシ）

### 原則

- **会員マスタは1枚**（Apomy・みんつく・プレジデントメイト共通）  
- プロフィール項目は共有  
- 社長マーク列は既存をゲートに使う  
- 掲載は **専用列** でみんつくと同じ分離  

### 既存列

| 列 | 役割 |
|------|------|
| 社長マーク | 入室資格・一覧の必須条件 |
| 社長マーク状態 | 申請中などは入室不可の判定に使える |
| 掲載中 | Apomy専用（プレジデント一覧では見ない） |
| 社名 | 社長カード表示（既存どおり） |

### 追加列（確定）

| 列名 | 必須 | 内容 |
|------|------|------|
| プレジデントメイト掲載 | **必須** | 空欄またはTRUE＝一覧に出す／FALSE＝停止 |
| プレジデント番号 | **必須** | 例: `社長12`。一覧取得時または本人初回入室で自動採番 |

### みんつくについて

みんつくも **会員マスタは分けない**（現行どおり）。  
プレジデントメイト追加を理由にみんつくを別スプシへ分離しない。

## 11. エンジニア向け補足

- 前例: みんつくは `app=mintuku` + 薄い `mintuku/` 入口＋専用掲載列。同様に `president/` と `プレジデントメイト掲載` / `プレジデント番号` を足す  
- ゲートは **画面だけでなく GAS** でも判定  
- Apomy導線ボタンは `index.html` の `#btn-region-link` 直下に配置  
- プロフィール編集は共通 `edit-screen`（モード差分は申請ボタン表示など最小限）  
- `Code.gs` 変更後は **Apps Script 再デプロイ必須**  
- アイコン／ログイン画像はリポジトリに実ファイルを同梱すること（参照: `president/img/`）

想定ファイル（新規・変更）:

| パス | 内容 |
|------|------|
| `president/index.html` | 薄い入口 |
| `president/icons/*` | 専用アイコン |
| `js/app-mode.js` | `app=president` |
| `js/app.js` / `index.html` / `css/` | モード分岐・導線ボタン・UI隠し・ブランド |
| `gas/Code.gs` | 掲載フラグ・承認ゲート・一覧条件 |
| `docs/プレジデントメイト仕様書.md` | 本資料 |

## 12. 受け入れ条件（実装完了の目安）

1. 社長マーク承認者が専用ログイン／導線から入れる  
2. 未承認者が導線を押すと、指定文言が出て遷移しない  
3. 直URLでも未承認は入れない  
4. サロン申請・社長マーク申請ボタンがプレジデントメイトに出ない  
5. 一覧は `社長マーク` かつ `プレジデントメイト掲載 ≠ FALSE`（空欄も出す）  
6. 番号は `社長N`。一覧取得時または本人初回入室で未採番者へ付与  
7. 繋がるは社長帯のみ  
8. 未承認ログイン時は指定トーストを出して入室させない  
9. バナーは対象アプリ列で出し分け  
10. Apomy／みんつく／プレジデントの掲載停止が互いに独立  
11. 会員データは同一行（二重マスタにならない）  
12. ホーム画面追加で専用名・専用アイコンになる
