## はじめに（この文書の読み方）

みんつくは、いま動いている **Apomy（全国版）** に追加する予定の **地方版** です。  
この文書は「これから作るもの」の取り決めです。

| 読みたい人 | おすすめ |
|------------|----------|
| オーナー・お客様 | 1〜3章、5〜8章 |
| 運用担当 | 5〜9章（掲載・お金・問い合わせ） |
| エンジニア | 全体。とくに 4・9・11・13章 |

Apomy本体の説明は別紙 `Apomy仕様書.md` を見てください。  
みんつくは **見た目や操作の多くをApomyと同じ** にし、違うところだけこの文書に書いています。

### 用語のやさしい説明

| 用語 | 意味 |
|------|------|
| Apomy | 全国の人が見られるマッチング（既存） |
| みんつく | 自分の地方の人だけが見られるマッチング（これから作る） |
| みんつく○○ | 地方名付きの呼び名（例: みんつく関東） |
| 現在地 | プロフィールで選ぶ都道府県 |
| 地方 | 北海道・東北など、都道府県をまとめた8つのグループ |
| 掲載 | 他の人の一覧に自分が出ること |
| ホーム画面に追加 | スマホにアプリアイコンとして置くこと |
| スプレッドシート（スプシ） | データを入れる表（Apomyと共通） |
| 無料期間 | 初めてみんつくを使った日から30日間、お金なしで使える期間 |
| 課金有無 | 有料契約があるかどうかを、表に手で書く印 |

## 1. みんつくでやりたいこと

お客様は「地方ごとに別アプリを8つ作りたい」と考えています。  
ただし、本当に8つ作ると、同じ修正を8回する必要があり、運用も大変です。

そこで次の方針にします。

> **中身のアプリは1つだけ。**  
> 見た目の名前・アイコン・「誰を一覧に出すか」だけ地方別に変えて、  
> **まるで地方アプリが複数あるように見せる。**

会員などのデータも、**Apomyと同じスプレッドシート** を使います。

## 4. どうやって「地方アプリ」に見えるようにするか

### 4.1 基本の考え方

1つのウェブサイト／プログラムのまま、  
「いまはみんつくの関東です」のように **種類と地方を付けて開く** イメージです。

一般の利用者は、難しいアドレスを覚える必要はありません。  
Apomyの「地域を選ぶ」から、自動で開く想定です。

（エンジニア向け：開き方の例）

```
…/index.html?app=mintuku&region=kanto
```

### 4.2 Apomyからの入り方

1. Apomyで「条件から絞り込む」→「地域を選ぶ」を押す  
2. 自分の現在地から地方を決める（例: 東京都 → 関東）  
3. 「みんつく関東」として開く  
4. 最初に **「みんつく関東」** のような名前の案内画面を出す  

現在地が未設定・海外などの場合は、今までどおり案内して開きません。

### 4.3 ホーム画面に追加したとき

| どこから追加したか | ホーム画面に出る名前 | アイコン |
|--------------------|----------------------|----------|
| Apomyから | apomy | Apomy用 |
| みんつくから | みんつく○○ | みんつく用 |

- みんつく用のアイコンは **必ず用意する**
- 「全地方で同じ絵か／地方ごとに色を変えるか」は **あとで決める**

※すでにApomyとして追加済みのアイコンを、あとから自動で「みんつく○○」に書き換えることは、スマホの仕組み上できません。この点は仕様として受け入れます。

## 5. みんつくで見える人・見えない人

みんつくの一覧に出るのは、次を **全部満たす人だけ** です。

1. 現在地が、いま開いている地方に入っている  
2. 「みんつく掲載」が「はい」になっている  
3. 見ている側が、無料期間中または有料契約済みである（第7章）

**他の地方の人は、みんつくの中では一切出ません。**  
検索しても、一覧をスクロールしても見えません。

---

## 6. 掲載のオン／オフ（Apomyと分ける）

やりたいこと:

- みんつくには出したいが、Apomy（全国）には出したくない、という状態を作れる  
- みんつくで「Apomyの掲載を停止」しても、**みんつくには出し続ける**

そのため、スイッチを2つに分けます。

| スイッチ名（案） | 意味 |
|------------------|------|
| 掲載中 | Apomy（全国）の一覧に出すか ※いまもある項目 |
| みんつく掲載 | みんつくの一覧に出すか ※新しく追加する項目 |

### みんつくの画面で押せるボタン（予定）

| ボタン（名前はあとで調整してよい） | 結果 |
|--------------------------------------|------|
| Apomyの掲載を停止 | 全国の一覧から消える。**みんつくには残る** |
| みんつくの掲載を停止 | みんつくの一覧から消える |

再開も、それぞれ別々にできるようにします。

新しく登録した人について、最初から「はい」にするタイミングは、作る直前にもう一度確認します。

## 7. お金のルール（みんつくだけ）

Apomyは今までどおり無料です。  
**お金の確認はみんつくだけ** で行います。

### 7.1 運用で持つ情報

| 項目 | 誰が書くか | 意味 |
|------|------------|------|
| みんつく初回ログイン日 | システムが自動（最初の1回だけ） | 無料期間のスタート日 |
| 課金有無 | 運用者がスプレッドシートに手で入力 | 有料契約があるか |

「今日で何日目か」という数字そのものは、毎日表に書きません。  
使うたびに、「初回ログイン日から何日経ったか」を計算します。

### 7.2 使える／使えないの判定

1. 初めてみんつくに入った日を記録する → ここから30日間は無料で使える  
2. 31日目以降  
   - 課金有無が「はい」→ 今までどおり使える  
   - 課金有無が「いいえ」（または空）→ 使えない（期限切れの画面）

### 7.3 期限が切れたときに出す文章

決まった文言:

> 無料期間(30日)が終了しました。今まで通り閲覧するにはこちらからお問合せください

- 「**こちら**」だけリンクにする  
- リンク先は **スプレッドシートの設定（またはマスタ）から取る**  
- 期限切れ中は、会員を探したり見たりはできない（問い合わせだけ、など最小限）

### 7.4 抜け道を防ぐ

画面側だけで止めると、細工で見続けられる恐れがあります。  
そのため、裏の処理側でも「みんつくを使っているか」「無料期間中か／有料契約があるか」を確認します。

## 10. やらないこと（はっきりさせる）

次は、意図的にやりません。

- 地方ごとに、別アプリ・別プログラム置き場・別スプレッドシートを8つ作ること  
- クレジットカード決済などを、システムに組み込むこと（当面はスプレッドシートへの手入力）  
- すでにApomyとして入れたアイコンを、勝手にみんつく名へ変えること

## 13. エンジニア向け補足（短く）

- Apomyと同じプログラムを使い、「みんつくかどうか」「どの地方か」で動きを分ける  
- 地方を表す記号の例: `hokkaido` / `tohoku` / `kanto` / `chubu` / `chugoku` / `shikoku` / `kinki` / `kyushu-okinawa`  
- ホーム画面の名前を分けるため、地方ごとの追加情報ファイル（manifest）を用意する想定  
- お金の判定や地方での絞り込みは、画面だけでなく裏の処理（GAS）でも行う  

詳しいApomy側の仕様は `Apomy仕様書.md` を正とします。
