## はじめに（この文書の読み方）

みんつくは、いま動いている **Apomy（全国版）** に追加する **地方版** です。  
見た目や操作の多くを Apomy と同じにし、違うところだけこの文書に書いています。

| 読みたい人 | おすすめ |
|------------|----------|
| オーナー・お客様 | 1〜3章、5〜8章 |
| 運用担当 | 5〜9章（掲載・お金・問い合わせ） |
| エンジニア | 全体。とくに 4・9・11〜13章 |

Apomy本体の説明は別紙 `Apomy仕様書.md` を見てください。

### 用語のやさしい説明

| 用語 | 意味 |
|------|------|
| Apomy | 全国の人が見られるマッチング（既存） |
| みんつく | 自分の地方の人だけが見られるマッチング |
| みんつく○○ | 地方名付きの呼び名（例: みんつく関東） |
| 現在地 | プロフィールで選ぶ都道府県 |
| 地方 | 北海道・東北など、都道府県をまとめた8つのグループ |
| 掲載 | 他の人の一覧に自分が出ること |
| ホーム画面に追加 | スマホにアプリアイコンとして置くこと（PWA。フェーズ4） |
| スプレッドシート（スプシ） | データを入れる表（Apomyと共通） |
| 無料期間 | 初めてみんつくを使った日から30日間、お金なしで使える期間 |
| みんつく課金終了日 | 有料契約の期限。入っていて今日以前でなければ有料。残り日数はこの日までのカウントダウン |
| 地方トークン | URLに載せる推測しにくい記号（例: `m8k4r1vz`）。地方IDの代わり |

## 1. みんつくでやりたいこと

> **中身のアプリは1つだけ。**  
> 見た目の名前・アイコン・「誰を一覧に出すか」だけ地方別に変えて、  
> **まるで地方アプリが複数あるように見せる。**

会員などのデータも、**Apomyと同じスプレッドシート** を使います。

## 4. 開き方（実装どおり）

### 入口

薄い入口ページ:

```
mintuku/index.html?r=（地方トークン）
→ ../index.html?app=mintuku&r=（同じトークン）
```

旧形式 `?region=kanto` も互換で受け付けますが、**新規導線はトークン（`r=`）を使います。**

Apomyの「地域を選ぶ」→ 現在地から地方を判定 → 上記入口へ進みます。

### なぜトークンか

`region=kanto` のように地名がURLに出ると、他地方を推測して開きやすくなります。  
そのため表向きのURLは不透明なトークンにしています。

**本丸の防御:** GAS側で「閲覧者の現在地がその地方か」を確認します。一致しない場合は一覧を拒否し、自分の地方へ寄せます。

## 5. 掲載の出し分け

フラグは2つです。

| 列 | 意味 |
|------|------|
| `掲載中` | Apomy（全国）の一覧に出すか |
| `みんつく掲載` | みんつく地方一覧に出すか |

みんつくのマイページ操作:

| 操作 | 結果 |
|------|------|
| Apomy上で Apomy掲載を停止 | `掲載中`＋`みんつく掲載`＋`プレジデントメイト掲載` をすべて FALSE。その後 **強制ログアウト** |
| みんつく／PM上で Apomy掲載を停止 | `掲載中` のみ FALSE（`keepRelated`。みんつく／PM掲載は残す） |
| Apomy掲載を再開 | `掲載中` のみ TRUE。みんつく／PMは **戻さない**（空欄のときだけみんつく掲載ON＋番号採番） |
| みんつくの掲載を停止／再開 | `みんつく掲載` だけ変更（通常はスプシ）。`掲載中` は変えない |

**一覧の参照ルール**

- Apomy一覧 → **`掲載中=TRUE`**
- みんつく一覧 → **現在地がその地方** かつ **みんつく明示停止でないこと**（`掲載中` は見ない）

**停止の連動**

- **Apomy画面から停止** → みんつく／PMも停止（連動・デフォルト）。画面は強制ログアウト
- **みんつく／PM画面から Apomy だけ停止** → みんつく／PMは残る。その後 Apomy を開くと（みんつく優先、なければ PM へ）直接遷移
- みんつくだけ停止（スプシ）・Apomy掲載中 → **全国には出る／地方には出ない**
- Apomy再開 → **みんつく／PM掲載は戻さない**

**Apomy掲載開始時の連動**

- `掲載中` を TRUE にしたとき（初回掲載など）:
  - `みんつく掲載` が **空欄** なら TRUE にする（FALSE は触らない）
  - 現在地から地方を判定し **みんつく番号** を採番（未採番のとき）

補足:

- みんつく／PM掲載中で Apomy だけ停止している場合、Apomy起動時に直接そちらへ遷移
- 復旧用: Apomyを `?stay=1` で開くと自動遷移しない

## 6. みんつく番号

- 初回みんつくアクセス時に、地方ごとの番号を自動採番（例: `関東12`）
- 画面では `No.00012` のように数字だけ見せる（Apomy会員番号はみんつくでは出さない）
- 欠番は埋めない
- 現在地変更で地方が変わったら番号を付け直す

## 7. お金（無料30日）

| 持つもの | 役割 |
|----------|------|
| `みんつく初回ログイン日` | 無料期間の起算（システムが初回だけ自動記録） |
| `みんつく課金終了日` | **日付ありかつ今日以前でない＝有料の主キー。** マイページは終了日までの残り日数（旧列名「課金終了日」は互換で読取可） |

※運用上の契約はだいたい1年だが、**プログラムに年数の縛りは持たない**。期限はスプシの終了日だけを見る。  
※旧列 `課金有無` / `みんつく課金開始日` は使わない（判定から削除）。

判定:

1. 初回日から **0〜29日目** → 無料で利用可  
2. **30日目以降** → `みんつく課金終了日` があり **今日 ≤ 終了日** のときのみ利用可  
3. 期限切れ → 一覧・検索は不可。**課金案内画面**を表示

課金案内画面の内容:

- 料金説明（1名1円1年・地域人数で金額変動・最低100円）
- **現在の地域人数**（8地方・リアルタイム集計）
- ① PayPay送金 → ② Googleフォーム報告 → ③ 公式LINEから連絡

### 設定・マスタ（期限切れ画面）

| キー / 区分 | 場所 | 内容 |
|-------------|------|------|
| `みんつくPayPayURL` | 設定シート | PayPay送金リンク（有効期限があるため随時更新） |
| `みんつくフォームURL` | 設定シート | 名前・送金時間の報告フォーム |
| 区分=`公式LINE` | マスタシート | アポイントメイト公式LINEのURL（アクセス拒否画面と同じ参照） |

旧キー `みんつく問い合わせURL` はフォームURLの互換フォールバックとして読めます。

### マイページ表示（実装）

みんつくモードのマイページ「みんつく利用状況」:

| 状態 | 表示 |
|------|------|
| 未課金（終了日なし／無料期間中） | 初回ログイン日・無料の経過日数・残り日数 |
| みんつく課金終了日あり（有効） | みんつく課金終了日・**残り日数**・有料契約中 |
| 終了日が過去（無料も終了） | みんつく課金終了日・期限切れ |

## 8. 現在地の変更

| ルール | 内容 |
|--------|------|
| 初回の現在地入力 | 無料（変更日は書かない） |
| その後の変更 | 確認のうえ `現在地変更日` を記録 |
| ロック | 変更後 **30日間** は変更不可（画面＋GAS） |
| 地方が変わったとき | みんつく番号を付け直し（欠番は埋めない） |

## 9. スプレッドシート（運用）

### 会員シート（追加列）

| 列名 | 必須 | 内容 |
|------|------|------|
| みんつく番号 | 推奨 | 例: `関東1`。空なら初回アクセス／Apomy掲載時に自動 |
| みんつく掲載 | 推奨 | `TRUE` / `FALSE`。Apomy掲載開始時に空欄なら TRUE |
| みんつく初回ログイン日 | 推奨 | 自動記入 |
| みんつく課金終了日 | 推奨 | 手入力の期限日。今日以前でなければ有料・残り日数表示 |
| 現在地変更日 | 推奨 | 変更ロック用。自動記入 |

### 設定シート

| キー | 内容 |
|------|------|
| みんつくPayPayURL | 期限切れ画面の PayPay 送金リンク（期限切れしたら更新） |
| みんつくフォームURL | 期限切れ画面の GoogleフォームURL |
| （マスタ）公式LINE | 期限切れ画面の公式LINEボタン（既存のアクセス拒否と同じ） |

### API（追加）

| action | 内容 |
|--------|------|
| `mintukuRegionCounts` | 8地方の現在地人数（認証不要・期限切れ画面用） |

### 実装方針（合意）

- **B + 薄いみんつく**: `mintuku/` は入口のみ。UI本体は共通 `index.html` + `js/`
- GAS・スプシは共通。コメントで `[共通]` / `[Apomy]` / `[みんつく]` を明示
- Apomy本番を壊さないため、**develop確認 → prod** の流れ

### 意図的にやらないこと

- 地方ごとに別アプリ・別GAS・別スプシを8つ作ること  
- クレジットカード決済の組み込み（当面はスプシ手入力）  
- すでに Apomy として入れたホームアイコンを勝手にみんつく名へ変えること

## 12. エンジニア向け補足

- 起動: `app=mintuku` + `r=`（トークン）または旧 `region=`（地方ID）
- 地方ID例: `hokkaido` / `tohoku` / `kanto` / `chubu` / `kinki` / `chugoku` / `shikoku` / `kyushu-okinawa`
- トークン対応は `js/app-mode.js` と GAS `resolveMintukuRegionId_` で揃える
- お金・地方絞り込み・掲載フラグは **画面だけでなく GAS でも判定**
- `Code.gs` の変更は **Apps Script の再デプロイが必須**（GitHub pushだけでは反映されない）

詳しい Apomy 側の仕様は `Apomy仕様書.md` を正とします。
