## はじめに（この文書の読み方）

みんつくは、いま動いている **Apomy（全国版）** に追加する **地方版** です。  
見た目や操作の多くを Apomy と同じにし、違うところだけこの文書に書いています。

| 読みたい人 | おすすめ |
|------------|----------|
| オーナー・お客様 | 1〜3章、5〜8章 |
| 運用担当 | 5〜9章（掲載・お金・問い合わせ） |
| エンジニア | 全体。とくに 4・9・11〜13章 |

Apomy本体の説明は別紙 `Apomy仕様書.md` を見てください。

### 用語のやさしい説明

| 用語 | 意味 |
|------|------|
| Apomy | 全国の人が見られるマッチング（既存） |
| みんつく | 自分の地方の人だけが見られるマッチング |
| みんつく○○ | 地方名付きの呼び名（例: みんつく関東） |
| 現在地 | プロフィールで選ぶ都道府県 |
| 地方 | 北海道・東北など、都道府県をまとめた8つのグループ |
| 掲載 | 他の人の一覧に自分が出ること |
| ホーム画面に追加 | スマホにアプリアイコンとして置くこと（PWA。フェーズ4） |
| スプレッドシート（スプシ） | データを入れる表（Apomyと共通） |
| 無料期間 | 初めてみんつくを使った日から30日間、お金なしで使える期間 |
| 課金有無 | 有料契約があるかどうかを、表に手で書く印 |
| 地方トークン | URLに載せる推測しにくい記号（例: `m8k4r1vz`）。地方IDの代わり |

## 1. みんつくでやりたいこと

> **中身のアプリは1つだけ。**  
> 見た目の名前・アイコン・「誰を一覧に出すか」だけ地方別に変えて、  
> **まるで地方アプリが複数あるように見せる。**

会員などのデータも、**Apomyと同じスプレッドシート** を使います。

## 4. 開き方（実装どおり）

### 入口

薄い入口ページ:

```
mintuku/index.html?r=（地方トークン）
→ ../index.html?app=mintuku&r=（同じトークン）
```

旧形式 `?region=kanto` も互換で受け付けますが、**新規導線はトークン（`r=`）を使います。**

Apomyの「地域を選ぶ」→ 現在地から地方を判定 → 上記入口へ進みます。

### なぜトークンか

`region=kanto` のように地名がURLに出ると、他地方を推測して開きやすくなります。  
そのため表向きのURLは不透明なトークンにしています。

**本丸の防御:** GAS側で「閲覧者の現在地がその地方か」を確認します。一致しない場合は一覧を拒否し、自分の地方へ寄せます。

## 5. 掲載の出し分け

フラグは2つです。

| 列 | 意味 |
|------|------|
| `掲載中` | Apomy（全国）の一覧に出すか |
| `みんつく掲載` | みんつく地方一覧に出すか |

みんつくのマイページ操作:

| 操作 | 結果 |
|------|------|
| Apomyの掲載を停止／再開 | `掲載中` だけ変更。みんつくには残る／戻る |
| みんつくの掲載を停止／再開 | `みんつく掲載` だけ変更 |

補足:

- Apomy側の「掲載停止」は従来どおり全国のみ（必須プロフィール復帰あり）
- みんつくから Apomy 掲載を止めたあと、Apomyを開くと **一度だけ** みんつくへ誘導する（明示停止時の旗）
- 復旧用: Apomyを `?stay=1` で開くと自動遷移しない

## 6. みんつく番号

- 初回みんつくアクセス時に、地方ごとの番号を自動採番（例: `関東12`）
- 画面では `No.00012` のように数字だけ見せる（Apomy会員番号はみんつくでは出さない）
- 欠番は埋めない
- 現在地変更で地方が変わったら番号を付け直す

## 7. お金（無料30日）

| 持つもの | 役割 |
|----------|------|
| `みんつく初回ログイン日` | 無料期間の起算（システムが初回だけ自動記録） |
| `課金有無` | 手入力。`TRUE` / `はい` など |

判定:

1. 初回日から **0〜29日目** → 無料で利用可  
2. **30日目以降** → `課金有無` がはいのときのみ利用可  
3. 期限切れ → 一覧・検索は不可。問い合わせ画面のみ

期限切れ文言:

> 無料期間(30日)が終了しました。今まで通り閲覧するにはこちらからお問合せください

「こちら」のURLは設定キー **`みんつく問い合わせURL`**。

### マイページ表示（実装）

みんつくモードのマイページに、次を出します。

- 初回ログイン日  
- 経過日数（○日目）  
- 無料期間の残り日数（または「有料契約中」「無料期間終了」）

## 8. 現在地の変更

| ルール | 内容 |
|--------|------|
| 初回の現在地入力 | 無料（変更日は書かない） |
| その後の変更 | 確認のうえ `現在地変更日` を記録 |
| ロック | 変更後 **30日間** は変更不可（画面＋GAS） |
| 地方が変わったとき | みんつく番号を付け直し（欠番は埋めない） |

### 実装方針（合意）

- **B + 薄いみんつく**: `mintuku/` は入口のみ。UI本体は共通 `index.html` + `js/`
- GAS・スプシは共通。コメントで `[共通]` / `[Apomy]` / `[みんつく]` を明示

## 12. エンジニア向け補足

- 起動: `app=mintuku` + `r=`（トークン）または旧 `region=`（地方ID）
- 地方ID例: `hokkaido` / `tohoku` / `kanto` / `chubu` / `kinki` / `chugoku` / `shikoku` / `kyushu-okinawa`
- トークン対応は `js/app-mode.js` と GAS `resolveMintukuRegionId_` で揃える
- お金・地方絞り込み・掲載フラグは **画面だけでなく GAS でも判定**
- `Code.gs` の変更は **Apps Script の再デプロイが必須**（GitHub pushだけでは反映されない）

詳しい Apomy 側の仕様は `Apomy仕様書.md` を正とします。
