## 1. Apomy とは

Apomy は、ビジネスパーソン同士がつながるための **マッチングサービス** です。

- **全国**の会員が対象です（地方限定ではありません）
- **永久無料**です（利用料の支払い・課金確認はありません）
- **Googleアカウント**でログインします
- スマホ向けに作られており、**ホーム画面に追加**してアプリのように使えます

ログイン画面のキャッチコピー:

> 永久無料、日本最速。ビジネスマッチングサービス。

---

## 2. 全体の仕組み（ざっくり）

ユーザーが見ている「画面」と、裏でデータを預かっている「表・プログラム」は役割が分かれています。

```
① スマホ／PC で Apomy の画面を開く
        ↓
② 画面（見た目・操作）が、裏のプログラムに「データをください」と依頼する
        ↓
③ 裏のプログラム（GAS）がスプレッドシートを読み書きする
        ↓
④ 結果が画面に表示される
```

| 役割 | 実体 | たとえ |
|------|------|--------|
| 画面 | ウェブサイトのファイル群 | お店の店頭 |
| 処理 | GAS（Code.gs というプログラム） | 店員さんの作業手順 |
| 会員データなど | Google スプレッドシート | 台帳 |
| 写真 | Google ドライブ | 写真の保管棚 |

**大事な運用ルール**

- 画面の見た目だけ更新しても、裏の処理（GAS）は自動では変わりません
- GASを直したあとは、スプレッドシートに紐づくプログラムへ内容を貼り直し、**使える状態へ再公開**する必要があります

### 開発用と本番用

| 呼び方 | 用途 |
|--------|------|
| 開発環境 | 試し打ち・確認用。開発用のスプレッドシートにつながる |
| 本番環境 | お客様が使う本物。本番用のスプレッドシートにつながる |

中身のプログラムはほぼ同じで、**どのスプレッドシート／どの接続先を見るか**だけが違います。

## 3. データの置き場所（スプレッドシート）

データはすべて Google スプレッドシートの「シート（タブ）」に分かれています。

| シート名 | 何が入っているか |
|----------|------------------|
| 会員 | 一人ひとりのプロフィールや、一覧に出す／出さないの状態 |
| バナー | ホームや「繋がる」に出すお知らせ画像 |
| 申請 | 社長マーク・サロン掲載などの申し込み内容と結果 |
| マスタ | 選択肢（性別・業種・タグなど）や公式LINEのリンク |
| 設定 | メンテナンスの切り替え、サロンのリンクなど、運用用のスイッチ |
| アクセス拒否 | ログインさせたくないメールアドレスの一覧 |

### 3.1 会員シートで特に大事な項目

| 項目名 | 他の人に見える？ | 説明 |
|--------|------------------|------|
| 会員番号 | 見える（No.） | 会員の通し番号 |
| Googleメール | 自分だけ | ログインに使うメール |
| ニックネーム | 見える | 一覧に出る名前。あとから変更できる |
| 本名 | 見えない | 最初の1回だけ登録。あとから自分では変えられない |
| 性別・年代・業種・職種 | 見える | プロフィールや検索に使う |
| 現在地・出身地 | 見える | 都道府県（海外も選べる） |
| 自己紹介など | 見える | 文章のプロフィール |
| タグ | 見える | 「カフェ会」などの興味タグ（最大6つ） |
| プロフィール画像 | 見える | 顔写真など |
| SNS（LINEなど） | 見える | 連絡先のリンク。**個人のLINEは必須** |
| 女性限定 | 見た目に反映 | 女性会員向けの設定。男性はその人のSNSを開けない |
| 年間経費 | 見えない | 本人の設定用。一覧には出さない |
| 社名 | 見える場合あり | 社長マークが付いた人向け |
| 掲載中 | （一覧の出し分け） | 「はい」の人だけ「繋がる」に出る |
| 社長マーク／サロン掲載 | 見える | 特別な印・カテゴリ |
| 登録日時・最終ログイン日時 | （数字の集計用） | ホームの人数表示などに使う |

### 3.2 マスタシート（選択肢の管理）

ここに書いた内容が、画面の選択肢になります。  
「有効」になっていない行は、画面に出ません。

よく使う種類:

- 性別、年代、業種、職種、都道府県
- タグ（プロフィールと検索の両方）
- 年間経費
- 地域リンク（「地域を選ぶ」で開く外部ページのアドレス）
- プライバシーポリシー（初回に見せる文章）
- 公式LINE（アクセスを拒否された人への問い合わせ先）

### 3.3 設定シート（スイッチ類）

| 設定名 | 何のため |
|--------|----------|
| アプリ名 | 表示用の名前 |
| サロンURL / サロンボタン名 | サロンへ案内するボタン |
| メンテナンス | 「はい（TRUE）」にすると、メンテ中画面になる |
| オーナーメール | メンテナンス中でも使える、オーナーのGoogleメール |
| 開発者メール | メンテナンス中でも使える、開発者のGoogleメール |

※オーナー／開発者のメールアドレスは、一般の利用者の画面には出しません。

### 3.4 アクセス拒否シート

- メールアドレスを1行に1件ずつ書く
- 書かれた人はログインできません
- 拒否された人には「公式LINEへ問い合わせ」画面が出ます

## 4. ユーザーの流れ（画面）

### 4.1 ログイン〜初回登録

1. Googleでログインする  
2. 初めての人は、まだ一覧に載らない（未掲載）  
3. 本名・ニックネームなど、必須項目を入れる  
4. プライバシーポリシーに同意する  
5. 保存すると掲載が始まり、「繋がる」に出るようになる  

**次のときは、プロフィール編集画面が必ず開きます**

- 初めてのログイン
- まだ一覧に出ていない（未掲載）
- ニックネームが空
- 本名が空

### 4.2 普段使う3つのタブ

| タブ | できること |
|------|------------|
| ホーム | 登録人数などの状況、検索への入口、お知らせバナー |
| 繋がる | 他の会員を見る・条件で絞り込む |
| マイページ | 自分の情報の編集、各種申請、掲載の停止、ホーム画面への追加 |

### 4.3 その他の画面

| 画面 | いつ出るか |
|------|------------|
| アクセス拒否 | 拒否リストに載っているメールで入ろうとしたとき |
| メンテナンス | 設定シートでメンテナンスを「はい」にしたとき |
| ウェルカム表示 | 新規の人向けの最初の一言（タップでスキップできる） |
| 条件から絞り込む | ホームや繋がるから検索条件を開いたとき |
| プロフィール編集 | マイページや、初回の必須入力のとき |
| 申請フォーム | 社長マーク・サロン掲載を申し込むとき |

## 5. ログイン・拒否・メンテナンス

### 5.1 ログインの考え方

- 使うのは **Googleアカウント**
- 一度ログインすると、同じ端末では続きから使いやすい（端末の中にログイン情報を保存）
- Googleの表示名で、ニックネームを勝手に上書きしません

### 5.2 アクセス拒否

運用者が「アクセス拒否」シートにメールを書くと、その人は入れません。  
画面では公式LINEへの問い合わせを案内します。

### 5.3 メンテナンス

| 項目 | 内容 |
|------|------|
| 始め方 | 設定シートの「メンテナンス」を「はい（TRUE）」にする |
| 一般の利用者 | 「メンテナンス中です。ご迷惑をおかけします。」だけ見える |
| 使える人 | 設定シートに書いた「オーナーメール」「開発者メール」の人だけ |
| 管理者の確認方法 | メンテ中に、管理者だけログインボタンを出せる（ロゴを短時間に5回タップ、または特別なURL） |
| 終わらせ方 | 「メンテナンス」を「いいえ（FALSE）」に戻す |

メンテナンス中も、オーナーと開発者は本番と同じ動きを確認できます。  
一般の利用者にはログインボタンを出しません。

## 6. プロフィールのルール

### 6.1 名前の使い分け

| 種類 | 他の人に見える？ | ルール |
|------|------------------|--------|
| ニックネーム | 見える | いつでも変更できる。一覧の名前になる |
| 本名 | 見えない | 最初の1回だけ。以降は自分では変更できない（変更は問い合わせ） |

### 6.2 変えられるもの／変えられないもの

| 項目 | ルール |
|------|--------|
| 性別 | 掲載が始まったあとは変更できない |
| ニックネーム | 変更できる |
| 本名 | 最初の1回だけ |
| 業種・職種・現在地など | 変更できる（マスタの選択肢から選ぶ） |

### 6.3 SNS

- **個人のLINEのURLは必須**（いちばん上に置く）
- 使える例: 個人用のLINEリンク（アドレスに `line.me` が含まれるもの）
- **使えないもの**: 公式LINEの短縮リンク（アドレスに `lin.ee` が含まれるもの）
- その他のSNSは最大3件（全体で最大4件）

### 6.4 タグ

- マスタにあるタグだけ選べる（最大6つ）
- 検索の「タグを絞る」でも使います

### 6.5 女性限定

- 性別が「女性」の人だけ設定できる
- 一覧にはプロフィールカードが見える
- ただし **男性が見ているとき、その人のSNSは開けない**（案内メッセージが出る）

### 6.6 掲載のオン／オフ

- 新規登録直後は **一覧に出ない（未掲載）**
- 必須のプロフィールを保存すると掲載が始まる
- マイページから掲載の停止・再開ができる
- 停止・再開の記録は「申請」シートにも残る

## 7. 「繋がる」で人を探す

### 7.1 どんな人が一覧に出るか

- **掲載中**の人だけ
- 見方の切り替え例:
  - 最近登録した人（登録から30日以内）
  - 会員番号のまとまり（100人ずつ）
  - 社長マークが付いた人
  - サロン掲載の人

### 7.2 「条件から絞り込む」

選べる条件:

- 性別（1つ）
- 年代・業種・職種・タグ（それぞれ複数選べる）
- 地域を選ぶ（自分の現在地から関連ページへ進む）

**検索の考え方（大事）**

- 同じ種類の中で複数選ぶ → 「どれか1つでも当てはまる人」（例: タグAまたはタグB）
- 違う種類を組み合わせる → 「どちらも満たす人」（例: 女性かつカフェ会タグ）
- 何も選ばない項目は、条件にしない

### 7.3 地域を選ぶ（いまの動き）

1. 自分のプロフィールの「現在地」を見る  
2. みんつくの8地方のどれかを決める  
3. **みんつく入口**（`mintuku/index.html?r=…`）を同じタブで開く  

現在地が未設定や海外などの場合は、案内を出して開きません。  
詳細は `みんつく仕様書.md` を参照。

## 8. ホームの数字（いまの状況）

日付の区切りは **日本時間（東京）** です。

| 表示名 | 意味 |
|--------|------|
| 現在登録人数 | 会員シートにいる人数（全員） |
| 昨日の新規参加者 | 昨日、新しく登録した人 |
| 昨日の掲載停止者 | 昨日ログインしていて、いま一覧に出ておらず、本名が入っている人 |
| 昨日の再参加者 | 昨日ログインし、登録は昨日より前で、いま掲載中の人 |
| 直近7日の新規 | 日ごとの新規登録数（グラフ） |

**補足:** 本名がまだ空の人（プロフィールが終わっていない人）は、「昨日の掲載停止者」に数えません。

## 9. 申請（社長マーク・サロン）

### 9.1 社長マーク

申し込みに必要なもの:

- 社名
- 法人番号（13桁）
- 証拠になるウェブのアドレス、または名刺などの画像

すでに申請中・許可済みの場合は、重ねて申請できません。

### 9.2 サロン掲載

- 公式LINEに入っていることが分かる画像が必要
- 画像は専用の保管場所（Googleドライブ）に保存されます

### 9.3 承認のしかた（運用）

- いまの主な運用は、**申請シートをオーナーが目で見て対応**することです
- 自動のメール通知は使っていません
- 承認されると、会員の「社長マーク」「サロン掲載」などの印が付きます
- サロン関係の見た目の呼び名に「井口の囲炉裏」という表示があります

## 10. バナー（お知らせ画像）

- 「有効」になっていて、開始〜終了の期間内だけ出ます
- 出す場所:
  - ホーム
  - 繋がる
  - 両方

表示の順番は、シートの「表示順」が小さいものから先です。

## 11. ホーム画面への追加

- Apomyはアプリストア配信ではなく、ブラウザから **ホーム画面に追加** できます
- 追加後の名前は「apomy」
- マイページなどから案内します
- iPhoneでは手順ガイドを表示します
- Android（Chromeなど）では、端末の「インストール」案内に対応します

## 12. エンジニア向け補足（処理の名前）

画面から裏のプログラムへ依頼するときの、主な処理の名前です。

| 処理名 | 何をするか |
|--------|------------|
| login | Googleログインの確認と、会員の登録／更新 |
| me / touch | 自分の情報の取得、最終ログイン時刻の更新 |
| users | 掲載中の会員一覧（条件付きも可） |
| banners / masters / settings / dashboard | 各データの取得 |
| updateProfile / uploadAvatar | プロフィール・画像の保存 |
| requestPresidentMark / requestSalonListing | 各種申請 |
| stopListing / resumeListing | 掲載の停止／再開 |
| ping | つながりの確認 |

開発と本番で違うもの（接続先）:

- プログラムの公開アドレス
- Googleログイン用のクライアントID
- スプレッドシートのID
- 画像保管フォルダのID

反映用の作業スクリプト:

- 開発向け: `scripts/push-dev.ps1`
- 本番向け: `scripts/push-prod.ps1`  
  （いったん本番用の接続設定に切り替え → 反映 → 開発用の設定に戻す）

## 13. ルール一覧（短く・わかりやすく）

1. Apomyは永久無料です。利用料の確認はありません。  
2. 新しく登録した人は、最初は一覧に出ません。必須プロフィールを保存すると掲載が始まります。  
3. 本名は他の人には見えません。登録は最初の1回だけです。  
4. 一覧に出る名前はニックネームです。  
5. 個人のLINEは必須です。公式LINEの短縮リンク（lin.ee）は使えません。  
6. タグの候補は、マスタシートで管理します。  
7. 「女性限定」でもカードは見えますが、男性はその人のSNSを開けません。  
8. ログイン拒否は、メールアドレス単位で設定します。  
9. メンテナンスは、設定シートの「メンテナンス」1項目で切り替えます。メンテ中に使えるのは、オーナーと開発者だけです。  
10. 「昨日の掲載停止者」は、本名が入っている人だけを数えます。
