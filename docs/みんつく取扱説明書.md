## この説明書について

みんつくは、**自分の地方の人だけ**と繋がれるマッチングです。  
操作の多くは Apomy と同じです。この文書では **みんつく特有の使い方** を説明します。

| 読みたい人 | 見る章 |
|------------|--------|
| はじめて使う会員 | 1〜6章 |
| 掲載の出し分け | 5章 |
| プロフィール・現在地 | 4章 |
| 無料期間・課金 | 6章 |
| 運用（スプシ） | 7章 |
| 困ったとき | 8章 |

---

## 1. みんつくとは

- **対象**: 現在地がその地方の会員だけ
- **データ**: Apomy と同じ会員表を使います（別アプリでも、人は同じ）
- **お金**: 初めて使った日から **30日間は無料**。その後は有料契約が必要です
- **見た目**: 地方名付き（例: みんつく関東）。アイコンはみんつく共通

Apomy（全国）とみんつく（地方）は **掲載のON/OFFを別々に** できます。

全国に出したくない場合は、Apomyの **`掲載中` をOFF** にすれば足ります（みんつくは `みんつく掲載` で別管理）。

---

## 2. 開き方

### おすすめの開き方（Apomyから）

1. Apomy にログインする
2. 「**条件から絞り込む**」を開く
3. 「**地域を選ぶ**」を押す（現在地から地方を判定）
4. 自分の地方のみんつくへ進む

**運用メモ**: 本番公開前など、Apomyの「地域を選ぶ」ボタンを **一時的に非表示** にしている場合は、下記の **URL直打ち** で開いてください。

### URLで開く場合

入口は次の形です（地方ごとにトークンが違います）。

```
…/mintuku/?r=（地方トークン）
```

開発例（関東）: `https://uotani-kyokoko.github.io/apomi-development/mintuku/index.html?r=m8k4r1vz`  
本番例（関東）: `https://fortunatunabiz.github.io/Apomy/mintuku/index.html?r=m8k4r1vz`

| 地方 | トークン（`r=`） |
|------|------------------|
| 北海道 | `m8h3k9qx` |
| 東北 | `m8t7n2wp` |
| 関東 | `m8k4r1vz` |
| 中部 | `m8c5p6yd` |
| 近畿 | `m8n9s0ue` |
| 中国 | `m8g2b8af` |
| 四国 | `m8s1d4jh` |
| 九州・沖縄 | `m8y6o3lm` |

**注意**

- 現在地が違う地方の入口を開いても、**自分の地方へ寄せられる／一覧は拒否**されます
- 地方の指定がない入口は開けません
- 旧形式 `?region=kanto` も動きますが、案内は **`r=` トークン** を使います

### ホーム画面に追加（アプリのように使う）

1. みんつくをブラウザで開く
2. マイページ右上の **ダウンロード（インストール）ボタン** を押す
3. 案内に従ってホーム画面に追加する

- 追加後の名前は **みんつく○○**（地方名付き）です
- すでにホーム画面から開いているときは、ボタンは出ません（追加済み）
- iPhone は Safari からの追加が必要です

---

## 3. ログインと初回

1. Googleアカウントでログイン
2. プロフィール未登録なら、案内に従って登録
3. 初めてみんつくを使うと、次が自動で行われます
   - **みんつく初回ログイン日** の記録（無料期間の起算）
   - **みんつく番号** の採番（例: 関東12 → 画面では `No.00012`）
   - 必要に応じて **みんつく掲載** がON

---

## 4. 画面の使い方（共通）

| タブ | できること |
|------|------------|
| ホーム | いまの状況・お知らせバナー（みんつく向けバナーのみ） |
| 繋がる | 同じ地方の会員一覧。条件から絞り込み可 |
| マイページ | 自分のプロフィール・掲載・利用状況 |

### 繋がる

- 一覧は **みんつく掲載がON** の人だけです（Apomyの `掲載中` は見ません）
- 「条件から絞り込む」で性別・年代・業種・職種・タグ・**都道府県**を選べます
- 番号は **みんつく番号** の数字です（Apomy会員番号は出しません）
- 繋がるメニューは **みんつく番号の帯** だけです（社長帯・サロン帯はありません）

### みんつくの中では「地域を選ぶ」はありません

他地方への切替は、みんつく内では行いません。  
別の地方を使うときは、その地方の入口から開きます（現在地が一致している必要があります）。

### プロフィール編集（Apomy共通）

- 編集画面は Apomy / みんつく / プレジデントメイト **共通** です
- **人脈拡大の為の年間経費（非公開）** は保存時に必須です（未入力のままでは保存できません）
- **現在地** を変えたあと **30日間** は再変更できません
- 地方が変わる引越しでは、**みんつく番号が付け直し** されます

## 5. 掲載の出し分け（重要）

みんつくのマイページでは、次を別々に操作できます。

| 操作 | 結果 |
|------|------|
| **Apomyの掲載を停止／再開** | 全国一覧だけ止まる／戻る。みんつくには残る／戻る |
| **みんつくの掲載を停止／再開** | 地方一覧だけ止まる／戻る |

覚え方:

- **Apomyに出たい** → Apomyの掲載をON（`掲載中`）
- **みんつくに出たい** → みんつくの掲載をON（`みんつく掲載`）
- **全国に出したくない** → Apomyの掲載をOFF（`掲載中=FALSE`）

Apomyの掲載を再開すると、空欄の **みんつく掲載** はONになり、必要なら **みんつく番号** も付きます（みんつく側を明示停止している場合は除く）。

## 6. 無料期間と課金

| 状態 | 内容 |
|------|------|
| 無料期間中 | 初回ログインから **0〜29日目** まで利用可 |
| 有料 | 運用がスプシの **みんつく課金開始日** に日付を入れた状態 |
| 期限切れ | 30日目以降で未課金。一覧・検索は使えず、問い合わせ案内のみ |

互換: **課金有無** が「はい／TRUE」でも有料扱いになることがあります（開始日が優先）。

### マイページ「みんつく利用状況」

- **未課金**: 初回ログイン日・経過日数・無料の残り日数
- **有料**: みんつく課金開始日・課金からの経過・有料契約中

期限切れのときは、画面の案内から問い合わせてください。  
（リンク先は設定シートの **みんつく問い合わせURL**）

## 7. 運用担当向け（スプシ）

### 会員シート

| 列名 | 運用でやること |
|------|----------------|
| 掲載中 | Apomy全国掲載。みんつく操作とは独立 |
| みんつく掲載 | 通常は会員操作。トラブル時のみ手直し |
| みんつく課金開始日 | 有料にした日を手入力（入っている＝有料） |
| 課金有無 | 任意（互換用） |
| みんつく番号 | 原則触らない（自動採番） |
| みんつく初回ログイン日 | 原則触らない（自動） |
| 現在地変更日 | 原則触らない（30日ロック用） |

### バナーシート

| 列名 | 内容 |
|------|------|
| 対象アプリ | 空欄＝全アプリ。`みんつく` と書くとみんつくのみ |

### 設定シート

| キー | 内容 |
|------|------|
| みんつく問い合わせURL | 期限切れ画面の「こちら」リンク |

**注意**: GAS（プログラム）を直したあとは、**Apps Script の再デプロイ**が必要です。GitHub への反映だけでは動きません。

## 8. 困ったとき

| 症状 | 確認すること |
|------|----------------|
| 他地方の人が見える／見えない | 現在地がその地方か。入口の `r=` が正しいか |
| 自分が一覧に出ない | マイページで「みんつくの掲載」がONか |
| Apomyに出たくないのに出る | マイページで Apomy掲載を停止（`掲載中=FALSE`） |
| プロフィールが保存できない | 年間経費（非公開）を選んだか |
| インストールボタンが出ない | すでにホーム画面から開いているか。マイページか |
| 無料が終わったと言われる | 初回から30日経過していないか。課金開始日が入っているか |
| 現在地が変えられない | 前回変更から30日以内はロックされます |
| 画面が古い／直らない | ハードリロード。GAS変更なら再デプロイ |

### Apomyへ戻したいとき

- マイページで **Apomyの掲載を再開**
- みんつくから Apomy 掲載を止めた直後に Apomy を開くと、**一度だけ** みんつくへ誘導されることがあります
- どうしても自動でみんつくへ飛ばされるときは、Apomyを `?stay=1` 付きで開くと自動遷移しません
